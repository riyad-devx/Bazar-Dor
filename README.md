
# 🛒 Bazar-Dor — বাজার দর

A Bangla market-price tracker for everyday essentials in Bangladesh.

বাজার দর হলো একটি responsive web application, যেখানে নিত্যপ্রয়োজনীয় পণ্যের দাম দেখা এবং বিভিন্ন category অনুযায়ী পণ্য খুঁজে পাওয়া যায়।

## ✨ Features

- 🏠 Responsive homepage and product listing
- 🗂️ Category-wise product browsing
- 📊 Product price and price-change information
- 🔐 Authentication with Better Auth
- 👤 User profile page
- 🛡️ Protected product and profile routes
- ⏳ Loading states and custom 404 page
- 📱 Mobile, tablet and desktop support

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/riyad-devx/Bazar-Dor.git
cd Bazar-Dor
```

Install dependencies:

```bash
npm install
```

Configure the environment variables required by your authentication setup in `.env.local`.

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
